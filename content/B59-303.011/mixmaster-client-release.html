Mixmaster Client Release

Lance Cottrell · 1995-02-05
I have put a SPARC executable for the Mixmaster client on my home page.

The brief asked for "the Mixmaster original README / announcement (1995)." This is it: the post that put a working Mixmaster client in people's hands. There was no separate release channel; a signed email to toad.com with a URL was how it shipped.
