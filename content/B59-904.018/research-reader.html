Development Tools and Software — Sega Mega Drive

Preservation record for Exodus Technical Documentation's catalogue of Sega Mega Drive / Genesis development software and test ROMs. The collection documents original-era tools such as Sega sample programs, GEMS, Psy-Q and SNASM2 toolchains, the Sierra 68000 C compiler, Microtec assemblers and compilers, plus hardware-verification ROMs used for emulator accuracy and preservation.

Citation

Provenance

Exodus Technical Documentation describes itself as a preservation-oriented technical reference for legacy console and arcade hardware, with a current focus on Sega platforms. Its Mega Drive software page distinguishes original development tools from modern/community tools and records recovered official sample code, toolchains, and test ROMs. Project B59 preserves a local research reader and canonical source trail rather than duplicating the hosted software collection.
