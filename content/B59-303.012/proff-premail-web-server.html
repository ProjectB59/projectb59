Premail Web Server Strangeness

Julian Assange · 1995-12-28
Surprising amount of information one can gain from an env array, really.

Assange joined the cypherpunks list in 1995 as proff@suburbia.net, running the Australian ISP Suburbia. His posts from this period are mostly like this one: short, technical, focused on where real systems quietly give away more than intended. The same instinct, minimise what a system reveals under observation, runs through Rubberhose and, later, WikiLeaks' submission design.
