## What This Is

A permanent offline mirror of the [Extropy-Chat mailing list](https://lists.extropy.org/pipermail/extropy-chat/) archives, with a focus on messages from **Hal Finney**, **Nick Szabo**, **Wei Dai**, **Adam Back**, **Tim May**, and other cypherpunks and digital-cash pioneers.

The Extropy lists were a key intellectual node in the 1990s–2000s where transhumanists, cryptographers, AI researchers, and libertarian technologists converged. Hal Finney posted here throughout his career — from PGP development to RPOW to his last years after Bitcoin.

This archive ensures those conversations survive even if `lists.extropy.org` goes down permanently.

## Quick Start

### 1. Install dependencies

```bash
pip install requests beautifulsoup4 lxml
```

### 2. Run the scraper

```bash
# Priority authors only (faster first run)
python vault_scraper.py --priority-only

# All messages from 2000 onward
python vault_scraper.py --start-year 2000

# Only the N most recent months the scraper finds (0 means no limit)
python vault_scraper.py --months 6

# Every month the scraper finds
python vault_scraper.py
```

Flags are `--priority-only`, `--start-year`, and `--months`. Output goes to `vault_data/`. The scraper waits 0.5 seconds between requests (`DELAY` in `vault_scraper.py`). There is no flag to change that delay. `vault_data/` is listed in `.gitignore` and is not part of this repository.

The month list and message parser expect an older pipermail page shape than the one `lists.extropy.org` serves now, so a run can finish without saving messages.

### 3. Open the reader

`vault.html` only redirects to `/`. The reader is `index.html`. Serve the repository over HTTP, because the page loads `vault-app/` scripts and optional `vault_data/index.json` with `fetch`:

```bash
python -m http.server 8000
```

Then open `http://127.0.0.1:8000/`.

Opening `vault.html` or `index.html` as local files (`file://`) does not open the reader. `vault.html` sends the browser to `/`. The catalog shipped in `vault-app/` and `content/` is what the site shows without a scrape. If `vault_data/index.json` is present beside `index.html`, the Extropy section loads that mirror.

## Archive content and fair use

This tool downloads publicly archived mailing list posts for personal research and preservation. Messages remain the copyright of their authors. Please scrape slowly, respect the archive's terms and robots.txt, and do not republish the collected data.

## Reader Features

- **Thread view** — full conversation trees, not just individual messages
- **Author spotlight** — biographical cards for Hal Finney and key cypherpunks
- **Priority filter** — one click to see only Hal + cypherpunk messages
- **Timeline sidebar** — navigate by month; sparkbar shows message density
- **Full-text search** — across subjects, authors, and message bodies
- **Quote detection** — distinguishes original text from cited replies
- **Dark terminal aesthetic** — because it fits

## Adding to This Vault

To add other mailing lists (e.g. the original Cypherpunks list, cryptography@metzdowd.com), edit `vault_scraper.py` and change `BASE_URL`. The parser does not match the pipermail HTML that lists.extropy.org serves now (month links, the author index, and message pages).

For non-Pipermail sources, the `parse_message()` function can be adapted.
